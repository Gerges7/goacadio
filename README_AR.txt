GoAcadio V2.3 — Generic Grading Systems (Cloudflare / React Router)

هذا التحديث يشمل ملفين فقط:
  app/lib/grading.ts
  app/routes/gpa-calculator.tsx

التغييرات:
1) إزالة «مثال توضيحي» من واجهة حاسبة GPA، وإزالة ربط أي سلم باسم جامعة.
2) تسمية السلالم حسب نقاط التقديرات: 4.0 (A=4.00, B+=3.30) و4.0 (A+=4.00, A=3.80).
3) إضافة سلم مخصص يستطيع الطالب فيه تحديد الحد الأقصى للمعدل (1 إلى 100) ورموز التقديرات ونقاطها، ليساعد من لا يجد السلم المناسب.
4) الإبقاء على تحويل النسب المئوية وحدود درجات السلم الثاني، وإظهار جدول النقاط.
5) الاحتفاظ بتوافق بيانات المتصفح المحفوظة من النسخة السابقة (mti/general-example).
6) إزالة الإشارات لجامعة بعينها من واجهة الحاسبة والوصف الإنجليزي والـMetadata.
7) لا تغييرات على Supabase أو قاعدة البيانات. ولا تغير أي ملفات أخرى.

للتحديث:
- على GitHub في المستودع goacadio، فرع main، استبدل الملفين بالأسماء والمسارات الموضحة.
- Cloudflare يبدأ Build/Deploy تلقائيا بعد Commit إن كان الربط مفعلا.
- اختبر رابط https://goacadio.com/tools/gpa-calculator بعد نجاح النشر.
- اختبر كلا السلمين وخيار السلم المخصص، وتأكد أن الحسابات القديمة المحفوظة في نفس المتصفح بقيت كما هي.

الفحص المنجز: تدقيق Syntax للملفين، واختبار حدود التحويل للنسب المئوية ومعادلة حساب المعدل وبعض فئات التقدير العام.
غير منجز هنا: Build كامل باستخدام حزم npm أو نشر فعلي على Cloudflare.

ملاحظة أكاديمية: اشتراك جامعتين في نفس سلم النقاط لا يعني تطابق سياسات الإعادة أو التصنيف العام أو حدود النسب المئوية.
