GoAcadio V3.7 — About, Terms & Public Trust
=======================================

التحديث مبني على آخر نسخة V3.6 على GitHub؛ ارفع الملفات المتغيرة فقط، ولا تحذف ملفات أخرى.
لا توجد Migration أو SQL جديدة أو مفاتيح AI أو Cloudflare جديدة.

الخطوات:
1. احتفظ بنسخة احتياطية من المشروع وقاعدة البيانات.
2. فك الضغط وارفع الملفات إلى Gerges7/goacadio على main بنفس المسارات.
3. بعد نجاح Cloudflare Deploy افتح /about و/terms من المتصفح.
4. جرّب التبديل عربي/إنجليزي، روابط التذييل، صفحة /help والصفحة الرئيسية.
5. اختبر الأوامر:
   npm run test:v37
   npm run test:v36
   npm run check:prelaunch
   npm run check:live
6. اختبر صفحة /contact من بريد حقيقي، وراجع النماذج والبيانات قبل الإطلاق.

تنبيهات:
- «شروط الاستخدام» مسودة تفسيرية قبل الإطلاق وليست وثيقة قانونية نهائية. يجب أن يراجعها صاحب الموقع ومستشار قانوني قبل اعتمادها.
- لا تدّعي الصفحات صفة جامعية رسمية أو شركة قانونية لم يتم توثيقها.
- لم نفتح Google Indexing: robots.txt ما زال Disallow: / والـmeta noindex مستمر.
- ملف sitemap.xml ليس منشورًا؛ يتم فقط تحديث docs/sitemap-public-template.xml.
- لا نفعّل AdSense أو ملفات تعريف ارتباط إعلانية، ولا ندّعي حصول موافقة من Google.
- اختبارات الكود المحلية لا تحل محل Build وCloudflare وSupabase الحقيقيين.
