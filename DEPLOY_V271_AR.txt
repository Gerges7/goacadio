GoAcadio V2.7.1 — PDF Reader Reliability Fix
==============================================

سبب الإصلاح:
OS deff.pdf (الملف المقدم للاختبار) يحتوي على 16 صفحة، حجمه 925,707 بايت، غير مشفر، وبه أكثر من 18 ألف حرف قابل للاستخراج. المشكلة ليست PDF ممسوحًا أو محميًا.
المسار القديم كان يعتمد على رابط منفصل لملف PDF.js worker وكان يخفي كل أسباب الفشل تحت رسالة PDF_READ عامة. لا يمكن الجزم بسبب الخطأ الفعلي في متصفح المستخدم دون لوج المتصفح؛ لذلك الإصلاح يدعم مسارين ويعرض تفاصيل الخطأ المساعدة.

الملفات المعدلة فقط:
- app/lib/pdf-text.client.ts
- app/routes/quiz-generator.tsx

التغييرات:
1) تحميل PDF.js worker مضمنًا عبر Vite (?worker&inline) لتفادي فقدان ملف worker أثناء النشر.
2) تجربة worker كملف asset (?url) تلقائيًا إذا فشلت الطريقة الأولى، بدون أي خدمات PDF خارجية.
3) إنشاء نسخة جديدة من ArrayBuffer لكل محاولة؛ PDF.js قد ينقل/يفصل الذاكرة إلى worker.
4) استمرار استخراج الصفحات الأخرى لو فشلت صفحة واحدة.
5) رسائل تفصيلية (بدون محتوى المحاضرة) تحت «تفاصيل الخطأ (للدعم الفني)» بدل رسالة عامة فقط.
6) مسح بيانات الملف القديم عند اختيار PDF جديد لتجنب استخدام نص قديم بالخطأ.

خطوات الرفع:
1) خذ نسخة احتياطية من GitHub.
2) افتح ZIP وارفع الملفين إلى نفس المسارات في مستودع Gerges7/goacadio على main، مع استبدال النسختين فقط. لا ترفع مجلد الاختبارات، ولا تحذف باقي الملفات.
3) انتظر نجاح Cloudflare Build + Deploy (npm install && npm run build).
4) اعمل تحديث إجباري Ctrl+F5، وافتح https://goacadio.com/quiz-generator
5) جرّب OS deff.pdf مرة أخرى. المفروض تشوف رسالة تم استخراج نص الصفحات. النص المستخدم يصل إلى 12,000 حرف كحد أقصى، ولذلك قد يُقرأ جزء من الـ16 صفحة فقط.
6) لو لسه فيه مشكلة، افتح «تفاصيل الخطأ (للدعم الفني)» وانسخ رسالة التشخيص؛ ما تبعتش كلمات مرور أو رموز الدخول.

لا تحتاج SQL جديد أو API keys أو تعديل Workers AI.
الملف الأصلي يتم قراءته على جهاز الطالب فقط، بدون رفع binary PDF لخوادم الموقع.

التحقق الحالي:
- الملف المقدم تم استخراج نصه باستخدام محرك PDF مستقل، والتأكد من كونه غير مشفر.
- فحص صياغة TypeScript للملفين تم، وفحص strict للمنطق مع stub types.
- لم يتم إجراء تجربة كاملة فعلية داخل متصفح على Cloudflare production أو اختبار pdfjs-dist v6.5.438 بعد بناء Vite، لأن node_modules لم تكن متاحة في بيئة العمل. لذلك مطلوب تجربة واقعية بعد النشر.
