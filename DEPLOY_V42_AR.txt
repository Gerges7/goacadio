GoAcadio V4.2 — إصلاحات الثقة والخصوصية قبل طلب مراجعة AdSense
================================================================

التحديث مبني على آخر نسخة مؤكدة في GitHub: V4.1 / main (commit f877ee3c83cd5df62d518169eb6d2c2473ee0697).

التغييرات:
- صفحة الشروط تعرض الشروط التشغيلية الحالية بدل تنبيه "مسودة قبل الإطلاق"، مع تاريخ السريان ووسيلة تواصل معلنة.
- صفحة الخصوصية توضح أنواع البيانات ومزودي الخدمة والاحتفاظ والحذف اليدوي، وطبيعة ملفات تعريف الارتباط المحتملة لدى Google عندما تُشغّل الإعلانات لاحقًا.
- تحديث معلومات التواصل في About وHelp وصفحة التسجيل: gergesmorad17@gmail.com.
- إضافة اختبار V4.2 إلى check:ci واختبارات الحفاظ على Meta Tag وads.txt والفهرسة الآمنة.
- لم يتم إضافة سكربت لعرض الإعلانات، ولم تتغير قواعد Supabase أو بيانات الطلاب أو حصص AI.

طريقة التركيب:
1) فك الضغط وارفع الملفات إلى GitHub > Gerges7/goacadio > main بنفس المسارات، مع استبدال الملفات المطابقة.
2) لا تمسح أي ملفات أخرى، ولا ترفع مجلد المشروع بالكامل من جديد.
3) افتح GitHub Actions وتأكد من نجاح GoAcadio build & quality check.
4) تأكد من نجاح Cloudflare Workers Build، ثم شغّل GoAcadio production smoke check يدويًا بعد انتهاء النشر.
5) راجع هذه الصفحات على الموقع الحي: /terms /privacy /about /contact /auth وملفات /ads.txt /robots.txt /sitemap.xml.
6) في AdSense > Sites > goacadio.com، إذا ظهر Requires review، نفّذ Verify ثم Request review من حسابك.

تنبيهات مهمة:
- لا تدّعي الاختبارات اعتمادًا قانونيًا أو موافقة Google. راجع النصوص المنشورة ومسؤوليات تشغيل طلبات حذف البيانات بصفتك مالك الموقع.
- الطلب المرسل لحذف الحساب لا يحذفه تلقائيًا حتى الآن؛ تابع الطلبات إداريًا.
- قبل عرض إعلانات للمستخدمين في EEA/UK/Switzerland فعّل Google-certified CMP حيث يلزم من AdSense Privacy & messaging.
- Google قد ترفض موقعًا رغم سلامة الكود بسبب محتوى قليل القيمة أو مشاكل جودة أو سياسات.
- صلاحية الربط الحالية لا تسمح للمساعد بالرفع المباشر؛ محاولة الرفع أعادت GitHub API 403. هذه الحزمة للرفع اليدوي فقط.
