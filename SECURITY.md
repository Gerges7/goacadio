# Security Policy

## Reporting a vulnerability

Please report suspected security issues privately to **support@goacadio.com** with the subject **Security Report — GoAcadio**.

Include:
- The affected page, endpoint or component.
- Clear reproduction steps and expected versus actual behavior.
- A minimal proof of concept using test data only.
- Any relevant request IDs or timestamps, with tokens and personal data removed.

Please do not:
- Access, modify, export or disclose another student's data.
- Include passwords, access tokens, API keys or private student records in a report.
- Run destructive tests, denial-of-service tests or automated scans against production without written authorization.
- Publish an unpatched vulnerability before coordinating a fix.

There is currently no public bug-bounty program. This policy does not authorize testing outside systems or accounts you own.
