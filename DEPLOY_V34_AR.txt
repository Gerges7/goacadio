GoAcadio V3.4 — Account Data Export & Privacy
=============================================

تحديث جزئي مبني على V3.3 الموجودة في Gerges7/goacadio على فرع main.
لا تنسخ المشروع كله ولا تمسح ملفات لا تظهر في ZIP.

الخطوات:
1) احتفظ بنسخة احتياطية من المشروع وبيانات Supabase.
2) فك ضغط ZIP وارفع محتوياته إلى GitHub main بنفس المسارات؛ استبدل الملفات المطابقة فقط.
3) Cloudflare هيبني وينشر التحديث بالطريقة المعتادة.
4) لا SQL جديد. يجب أن تكون migrations 001 إلى 007 موجودة ومطبقة في Supabase.
5) افتح https://goacadio.com/account بعد تسجيل الدخول.
6) اضغط «تجهيز نسخة JSON»، ثم «تنزيل الملف الآن». افتح الملف في محرر نصوص وتحقق من وجود account وcollections.
7) ابدأ بحساب اختبار جديد بدون بيانات، ثم جرّب حسابًا فيه مواد ونتائج اختبار محفوظة.
8) للتحقق من فصل البيانات: جرّب بحسابين مختلفين وتأكد أن JSON كل حساب لا يحتوي على بيانات الحساب الآخر.
9) اختبر «طلب نسخة من بياناتي» و«طلب حذف الحساب»؛ ما زالا موجودين، وطلب الحذف لا يحذف الحساب تلقائيًا.
10) بعد تثبيت dependencies نفّذ:
    npm run test:data-export
    npm run check:prelaunch
    npm run build

ما يتغيّر:
- وظيفة تصدير آمنة من المتصفح إلى ملف JSON لبيانات الطالب المملوكة له في الجداول الحالية.
- صفحة الحساب تعرض التقدم والأخطاء بشكل واضح ولا تسمح بتنزيل نسخة ناقصة إذا فشلت قراءة أحد الجداول.
- صفحتا الخصوصية والمساعدة تحددان حدود التصدير.
- script لاختبارات التصدير والتقسيم على صفحات pagination.

الحدود والتحذيرات:
- لا تُصدّر نسخًا احتياطية من قاعدة Supabase أو بيانات طلاب آخرين.
- البيانات تُقرأ مباشرةً بواسطة Supabase باستخدام جلسة الطالب وRLS؛ ما فيش Service Role Key.
- النصوص اللي ضمن طلبات الدعم/الحساب قد تكون شخصية؛ احفظ JSON في مكان آمن.
- التصدير لا يشمل السجلات الداخلية لدى Supabase/Auth/Cloudflare أو مسودات GPA/CV المحلية على أجهزة أخرى؛ الطلب الإداري للنسخة الكاملة ما زال متاحًا.
- حد ذاتي 10,000 سجل لكل جدول؛ لو تجاوز يتم إظهار خطأ بدل تصدير ناقص.
- حذف الحساب ما زال طلبًا يُعالج يدويًا؛ لا تَعِد بتنفيذ تلقائي.
- سياسة الخصوصية النهائية ووسيلة اتصال عامة موثقة ومراجعة الأمان ما زالت متطلبات إطلاق.
- إعدادات robots.txt وnoindex لم تتغير، وصفحة roadmap غير منشورة.
- لم يتم تشغيل Build كامل أو اختبارات حية على Supabase/Cloudflare في بيئة التجهيز.
