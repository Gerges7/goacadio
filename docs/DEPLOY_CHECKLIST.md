# GoAcadio — first deployment checklist

- [ ] GitHub repo `goacadio` contains `wrangler.json` at root
- [ ] Cloudflare Workers project name `goacadio`
- [ ] Git connected to `main`
- [ ] Build `npm run build`, deploy `npx wrangler deploy`
- [ ] `*.workers.dev` URL opens homepage
- [ ] All navigation routes display, language toggle works
- [ ] GPA, timer, CV and local dashboard smoke-tested
- [ ] Browser storage notice visible
- [ ] Custom domain `goacadio.com` bound under Worker Settings
- [ ] HTTPS works, optional www redirect configured
- [ ] No Ads/real signups/paid claims in demo
- [ ] Prior to public SEO launch: remove robots noindex and build real legal pages
