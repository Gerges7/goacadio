## 2. نطاق المنتج الحالي

### أدوات عامة
- GPA/CGPA مع أنظمة تقدير قياسية ومخصصة.
- Focus Timer.
- CV Builder محلي داخل المتصفح.
- دليل جامعات وكليات مصر والسعودية.
- أدلة تعليمية ومركز مساعدة.

### مساحة الطالب
- التسجيل والدخول بالبريد وكلمة المرور، وGoogle OAuth عند تهيئة المزود.
- الملف الأكاديمي والمواد.
- Study Planner والمهام والامتحانات.
- AI Study Assistant.
- إنشاء اختبارات من ملفات PDF النصية.
- Quiz History وStudy Stats وRevision recommendations.
- تصدير بيانات الحساب وطلبات الحذف والدعم.

### الخصوصية والأمان
- Supabase RLS للبيانات الخاصة بالمستخدمين وإجراءات الإدارة.
- GPA وCV محفوظان محلياً في المتصفح.
- استخراج نص PDF يتم في المتصفح؛ لا يتم رفع ملف PDF نفسه كملف دائم.
- طلبات AI تتطلب مصادقة وتخضع لحصة يومية مشتركة.
- صفحات الحساب والمساحة الخاصة وواجهات API تستخدم `no-store` و`noindex`.
- صفحة الخدمات قد تعرض سجل طلبات المستخدم؛ لذلك أضيف لها منع التخزين المشترك.
- تمت إضافة HSTS إلى استجابات HTTPS في آخر تحديث، وينتظر التحقق في CI والإنتاج.

## 3. حدود لم يتم إثباتها بعد

هذه الجولة لا تثبت نجاح كل مسار يتطلب حساباً حقيقياً. ما زال يلزم اختبار متصل بـSupabase وحساب اختبار مخصص للتحقق من:
- إنشاء حساب وتأكيد البريد وتسجيل الدخول والخروج واستعادة كلمة المرور.
- إعداد Google OAuth فعلياً.
- إنشاء وتعديل وحذف الملف الأكاديمي والمواد.
- حفظ واستعادة المهام والامتحانات وسجل الاختبارات.
- صلاحيات RLS بين مستخدمين مختلفين، واختبار حساب Admin.
- توليد AI فعلياً وحصة الاستخدام وربط Workers AI.
- تصدير البيانات وطلب الحذف من حساب حقيقي.

كذلك لا يثبت فحص HTTP أن نسخة Cloudflare المنشورة تطابق بالضرورة SHA الخاص بآخر Commit؛ فـGitHub quality gate يبني ويختبر ولا ينفذ النشر. يلزم التحقق من آخر Deployment في Cloudflare.

## 4. فجوات المنتج ذات الأولوية

| الأولوية | الإضافة | السبب |
|---|---|---|
| P1 | Flashcards + Spaced Repetition | ربط الاختبارات بالمراجعة المتباعدة ورفع الاحتفاظ بالمعلومة |
| P1 | AI generation للبطاقات من PDF/notes | إكمال مسار تحويل المحاضرة إلى أدوات تعلم |
| P1 | خطة مذاكرة تلقائية من المنهج ومواعيد الامتحانات | ربط Planner وRevision وQuiz history |
| P2 | PWA وOffline shell | تحسين الاستخدام على الشبكات الضعيفة والموبايل |
| P2 | تذكيرات وتقويم | زيادة الالتزام بالمذاكرة |
| P2 | توسيع دليل الجامعات بمصادر رسمية | الانتقال من مصر والسعودية إلى أسواق أخرى |
| P3 | لغات إضافية ومجموعات دراسة | توسيع الوصول والمجتمع |
| P3 | مدفوعات واشتراكات | نموذج دخل واضح بعد استقرار المنتج |

لا توجد حالياً بطاقات تعليمية أو نظام Spaced Repetition أو OCR أو مزامنة Google Calendar أو معالجة مدفوعات أو تطبيق PWA كامل.

## 5. الاختبارات المستمرة

- `npm run check:ci`: اختبارات الإصدار والوظائف وPlaywright وTypeScript وProduction build.
- `npm run check:live`: فحص صفحات الموقع المنشور وSEO وsecurity headers.
- `npm run check:api-guest`: رفض الطلبات غير المصرح بها والطلبات العابرة للمصدر.
- GitHub production smoke: بعد نجاح الجودة على `main`، ومجدول كل ست ساعات.

## 6. متطلبات إغلاق المراجعة

1. نجاح CI بعد آخر تحديثات HSTS وnpm audit.
2. نجاح Production smoke بعد التحديث.
